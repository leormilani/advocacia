## 📋 Sobre o Projeto

Este projeto foi construído para simular a presença digital de um escritório de advocacia de alto padrão. O design prioriza a sobriedade, a segurança jurídica e a facilidade de contato para potenciais clientes que buscam consultoria ou representação legal.

### ✨ Principais Funcionalidades

* **Design Responsivo & Executivo:** Layout adaptado perfeitamente para desktops, tablets e smartphones, utilizando paleta de cores corporativa (Azul Marinho, Slate e Dourado).
* **Modal Interativo de Consulta:** Formulário dinâmico integrado para envio de solicitações de atendimento inicial.
* **Componentização Avançada:** Arquitetura limpa em React dividida em componentes reutilizáveis (`Navbar`, `Hero`, `Areas`, `About`, `ContactModal`, `Footer`).
* **Botão Flutuante de WhatsApp:** Acesso rápido para contato imediato do cliente via chat.
* **Performance Otimizada:** Construído com Vite para tempos de carregamento instantâneos e pontuação máxima em otimização de SEO e responsividade.

---

## 🛠️ Tecnologias Utilizadas

* **React 18** (Biblioteca para construção da interface de usuário)
* **Vite** (Empacotador e servidor de desenvolvimento ultrarrápido)
* **Tailwind CSS** (Estilização utilitária moderna e responsiva)
* **Lucide React** (Biblioteca de ícones vetoriais limpos e modernos)

## ⚙️ Como Executar o Projeto Localmente

Certifique-se de ter o **Node.js** instalado em sua máquina. No terminal, execute os seguintes comandos:

```bash
# 1. Clone o repositório
git clone [https://github.com/leormilani/.git](https://github.com/leormilani/advocacia.git)

# 2. Acesse a pasta do projeto
cd escritorio-advocacia

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
